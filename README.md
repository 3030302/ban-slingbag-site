# Ban 펫 슬링백 랜딩 페이지

브라우저에서 바로 제공되는 정적 HTML 랜딩 페이지입니다. 별도 패키지 설치나 빌드 과정 없이 Vercel에서 배포할 수 있습니다.

## 로컬 미리보기

`index.html`을 브라우저에서 열거나 정적 파일 서버로 제공하세요.

## Vercel 배포

GitHub 저장소를 Vercel 프로젝트에 연결한 뒤 아래 설정을 사용하세요.

- Framework Preset: Other
- Root Directory: `.`
- Build Command: 비워 둠
- Install Command: 비워 둠
- Output Directory: `.`

이 프로젝트는 기존 저장소와 별도로 관리됩니다.
